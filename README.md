# Invitation au mariage de Raphaël & Charline

Site de l'invitation complète du 16 janvier 2027 : cérémonie civile, cérémonie
religieuse, goûter et vin d'honneur, puis soirée.

## Contenu

- `index.html` — la page unique, CSS et JavaScript inclus, sans dépendance externe
- `assets/` — signature manuscrite, illustrations et code-barres extraits en SVG
  depuis les faire-part d'origine, photo du couple, polices en woff2
- `robots.txt` — interdit l'indexation par les moteurs de recherche

## Notes

La page fonctionne hors ligne : toutes les polices et images sont locales.
Les textes reprennent mot pour mot les faire-part papier, l'année 2026 ayant été
ajoutée à la date limite de réponse (« vendredi 16 octobre 2026 »).

Les boutons « Itinéraire » ouvrent Google Maps, les boutons « Calendrier »
téléchargent un fichier `.ics` au fuseau Europe/Paris. Les heures de fin des
événements sont des estimations : les faire-part n'indiquent que les heures de
début, sauf pour le goûter et vin d'honneur (15h-18h).
